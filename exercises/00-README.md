# Упражнения по effector

28 практических задач в 4 уровнях (нумерация 2–5: уровень 1 — «чтение с вопросами» —
убран, номера сохранены ради соответствия с `TODO` в коде). Формат каждого задания:
*Файлы* (где работать) + условие + решение в `<details>`.

## Как учиться

Иди по порядку; внутри уровня задачи идут от простых к сложным.

Каждая задача — по схеме:

1. **Прочитай условие.** Где работать — в строке *Файлы*; подсказка — не всегда есть.
2. **Сделай.** Dev-сервер: `npm run dev` → http://localhost:5173.
3. **Проверь результат:**
   - всегда `npm run build` (типы + сборка);
   - если трогал модель — `npm test` (тесты проекта должны остаться зелёными);
   - если изменение визуальное — посмотри в браузере.
4. **Застрял / хочешь свериться** — открой `<details>` к задаче (до попытки — не подглядывай).
5. **Отметь** выполнено в «Плане и статусе» ниже (поставь `[x]`).

Свои тесты писать на уровнях 2–4 **не требуется** — их написание это уровень 5.
Команда `npm test` гоняет тесты проекта и страхует от поломки.

Главное правило проекта: **бизнес-логика — в `model/`, React — только читает сторы
и шлёт события**. Не нарушай его, даже если «проще прямо в компоненте».

## Конвенции проекта (важно!)

- effector **22.7.0** / effector-react **22.5.1** — те же версии, что в оригинальном проекте.
  API v23 (`fx.settled`, `debounce` из коробки, `Gate({component})`) здесь **не** работает.
- Индикатор загрузки — `fx.pending` (стор-булево).
- `attach({ effect: ... })` — только для **уже существующих** эффектов; «голая»
  асинхронная функция — в `createEffect`.
- Паттерн gate: `createGate()` в model → `useGate(XGate)` в компоненте →
  страница рендерит **сам компонент**. Важно: в v22 `<XGate />` в JSX всегда
  рендерит `null` — gate это сигнал «компонент на экране» + носитель состояния,
  а НЕ обёртка контента.
